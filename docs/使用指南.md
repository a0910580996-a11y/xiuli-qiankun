# 使用指南

## 选择一份锦囊

先按目标挑阶段，而不是从头套用全部提示词：

1. **厘清问题**：你知道自己遇到困难，但还没说清需要解决什么。
2. **建立认知**：你要理解概念、核查说法、分析优秀案例或研究一个对象。
3. **生成解法**：目标与约束已基本明确，正在寻找路径或机制。
4. **做出决策**：你有几个候选方向，想比较支持与反对的最强理由。
5. **行动验证**：你需要用一个成本低、可逆的小实验检验关键假设。

进入对应目录，打开一份锦囊，把方括号中的占位内容换成当前情境。尽可能说清楚目标、已知事实、限制和你不希望发生的事；只提供完成任务必要的信息。

## 交给智能体

### 智能体能读取 GitHub

发送仓库地址和 README 首页的引导语。请智能体先读 `AGENTS.md`，根据你的问题推荐一份锦囊，再说明如何个性化。它不应默认需要克隆代码或安装软件。

### 智能体不能读取 GitHub

从 GitHub 网页复制所需的单份 Markdown 内容，或上传该 `.md` 文件；然后告诉智能体你的目标和是否允许它改写提示词。

### 在本机代码智能体里使用

如果你已在本地克隆此仓库，可以让 Claude Code、Codex 等读取根目录 `AGENTS.md` 和相应文件。仅为阅读和改写提示词不需要安装依赖、运行脚本或提供 API 密钥。

## 示例

如果你说“我最近总拖延，但不知道从哪改起”，智能体可以先判断是否还需要澄清目标；当问题足够具体后，推荐“最小实验”，帮你把一个可能原因变成可在短周期内验证的行动。实际实验内容、周期和停止条件由你确认。

## 使用边界

提示词只是对话框架。具体事实、研究案例和专业结论需要根据实际情况查证。医疗、心理、法律、财务和安全问题不能仅凭 AI 回复作诊断或重大决定；不要向公共智能体输入不必要的可识别个人资料。
