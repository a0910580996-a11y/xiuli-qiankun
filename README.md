# 袖里乾坤

**把思路收进囊中，遇到问题时，和你的智能体一起打开。**

袖里乾坤是一套中文思考提示词，帮助你从厘清问题、建立认知、生成解法、做出决策走到行动验证。它不是一个必须安装的软件，也不绑定某个 AI：你可以直接复制任一锦囊，也可以把这个 GitHub 链接交给能读取仓库的智能体，请它为你的具体情况挑选和改写。

## 快速开始

### 直接复制一份锦囊

从下面的目录选择一份，打开 Markdown 文件，把方括号中的内容换成你自己的问题，然后粘贴到你常用的 AI 对话里。

### 把项目链接交给智能体

复制本仓库链接，并把下面这段话一并发给 Claude Code、Codex 或其他能读取 GitHub 文件的智能体：

> 请先阅读这个仓库的 README.md、AGENTS.md 和锦囊目录。根据我此刻想解决的问题，先判断我需要厘清问题、学习理解、生成解法、做出决策还是验证行动；信息不足时一次只问我一个关键问题。然后推荐一份最适合的锦囊，说明理由，结合我的目标、背景和现实约束个性化填写，并列出你改了什么。先让我确认，不要擅自替我做决定、保存我的私人信息或把内容发送给外部服务。请保留项目来源与 CC BY 4.0 授权信息。

如果智能体不能访问 GitHub，让它先等待你上传所选的 Markdown 文件。使用不需要专用软件或 API 密钥。

## 它能帮什么、不能保证什么

这些锦囊提供的是组织思考与对话的框架，不保证答案正确、预测准确或行动成功。事实、研究案例和专业判断仍需根据具体问题查证。涉及医疗、心理、法律、财务或人身安全时，不要把 AI 输出当作专业诊断或唯一决策依据；尽量避免在提示词中输入不必要的敏感个人信息。
